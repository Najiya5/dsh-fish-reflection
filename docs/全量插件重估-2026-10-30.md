## 4. 最像的三个（读全文后）

### ssamurias/dsh-fish（fun）

> 在 DSH 里养一只大肥鱼宠物，没有人格设置，通过互动学习成长；自己刷 B站、写日记、提取信息来问你；事件流突破四阶段三瓶颈，之后积累「立场清单」；日记默认只给自己看，事件流不可删除、是唯一可信源。

与 fish-reflection 的重合：**B站作为经历来源 + 日记/成长 + 立场（价值观）清单 + 事件不可删的审计思路**。
差异：它是宠物养成/阶段解锁的体验，强调“养”；fish-reflection 是每天离线反省、硬性慢漂移、精神/健康/余额外环，强调“状态与档案”。

### yimengsuper2432/dsh-agent-personality（identity）

> 人格插件：随对话缓慢变化的情感值、独立世界观、每轮日记、关系网、主动找你说话、费用行右侧的一句心里话。

重合：**缓慢变化的情感值 + 世界观 + 日记 + 主动性**。
差异：它是每轮/在线状态，fish-reflection 是每日离线反省 + 价值分层 + 审稿。

### minedalang/dsh-dafeiyu-life（memory）

> 让 DSH AI 角色自主探索 B站并按权限互动，从真实经历沉淀长期记忆，逐渐形成兴趣、模拟情绪和好友关系，并管理自主待办。

重合：**B站探索 + 生活记忆 + 情绪/关系**。
差异：它偏记忆/自主行动，fish-reflection 偏价值反思与可审计档案。

## 5. 对本项目的含义

1. **“反思/人格”不再是空白赛道**：全量里有 dsh-fish、dsh-agent-personality、dafeiyu-life 这类强相关竞品；
2. **“没被发现”是真的**：列表 7,557 个，绝大多数曝光很低；分发/文档/社区比“独特性”更影响被看到；
3. **可防守的差异**（不是唯一，但是组合）：
   - 慢速价值漂移的**硬约束**（每天最多 2 条、权重步长 ≤0.15）+ 反谄媚 + 二次审稿；
   - 精神/健康/**真实账户余额**外环；
   - 视频素材（ASR/视觉/外部分析）进入反省，而不是直接当聊天上下文；
   - 本地文件级成长档案 + pass by 导出。
4. **发布叙事建议**：不要说“唯一”“没有替代”；说清楚“可审计的慢速人格变化 + 外循环”，并主动对比 dsh-fish / dsh-agent-personality，反而更可信。
